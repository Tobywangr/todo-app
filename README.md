# 拾光待办桌面客户端

这是一个 Electron 桌面摆件版本的待办应用，启动后会以无边框、始终置顶的小窗口出现在屏幕右上角。

## 启动

```bash
npm install
npm start
```

窗口可以直接拖动顶部区域，右上角的 `−` 会最小化，`×` 会退出客户端。待办数据和计时进度保存在本机浏览器存储中。

## 功能

- **待办 / 已完成 / 回收站**：支持优先级标记、排序、随机挑选一件，右键还有快捷菜单。
- **专注节奏**：专注与休息两档计时，`↺` 重置、`↠` 跳到下一阶段；一个阶段结束后会自动切到另一个阶段（不会自动开始）。
- **自定义时长**：点「⚙ 自定义」可设置专注（1 - 180 分钟）与休息（1 - 60 分钟）时长，支持快捷档位和 ± 步进，保存后写入本机存储，重开应用依然生效。
- **收纳**：点标题栏的 `›` 把窗口收成屏幕右边缘的窄条，点窄条上的 `‹` 恢复原位置和原尺寸。

## 测试

```bash
npm test
```

会以真实窗口跑两个用例：`test/window-bounds.test.js` 验证收纳 / 展开能还原窗口尺寸，`test/timer-settings.test.js` 通过真实界面验证自定义时长的保存、夹紧、跳转与阶段切换。测试使用临时 userData 目录，不会读写正式数据。

## 打包

```bash
npm install
npm run build:linux
npm run build:windows
```

打包产物位于 `dist/`。Linux 构建生成 Ubuntu/Debian 可安装的 `.deb`；Windows 构建生成 x64 NSIS 安装程序 `.exe`。Windows 目标可在 Linux 上通过 Docker Wine 构建环境生成。
